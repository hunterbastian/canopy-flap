# Canopy Flap

A forest-canopy flappy game built with Vite and TypeScript. Guide a winged bronto through the grove, collect golden berries, nail perfect gap passes, and ride the wind at higher groves.

## Play locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Controls

- **Flap:** Space, W, Arrow Up, click, or tap
- **Retry:** Enter after a crash
- **Sound:** M or the sound toggle button
- **Fullscreen:** F

## Deploy

Production build outputs to `dist/`. The project is configured for Vercel via `vercel.json`.
